# 할 일: 정답을 가린 문제 풀기

이 메시지 끝에 펼친 문제 목록(JSON 배열)이 붙는다. 정답과 해설이 들어 있던 필드는 지웠고, 보기나 카드처럼 순서가 답을 흘리는 배열은 섞었다.

처음 보는 사람처럼 문제를 풀어라. 기획서의 원칙과 근거 요약만 보고 판단한다. 문제를 쓴 사람이 무엇을 의도했는지 짐작하지 않는다.

## 쓰는 방법

1. 스키마에서 이 문제의 형식을 찾아, 지워진 필드 가운데 정답을 정하는 필드를 확인한다.
2. 정답을 정하는 필드만 채우고, 나머지 지워진 필드는 비워 둔다.
3. 순서가 답인 배열은 네가 고른 순서로 늘어놓고, 다른 배열의 순서는 그대로 둔다.
4. 정답이 둘 이상이라고 생각해도 하나를 고른다. 망설인 이유는 쓰지 않는다. 다음 단계에서 다른 검토자가 정답과 비교한다.

## 출력 모양

받은 배열과 같은 길이, 같은 순서의 JSON 배열이다. 원소는 받은 문제에 네가 고른 정답 필드를 채운 것이다. `id`와 다른 필드는 바꾸지 않는다.
