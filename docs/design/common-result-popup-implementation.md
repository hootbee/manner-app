# 01–06 공통 결과 팝업

2026-11-22. `MANNERS_common_result_popup_user_sfx_final.zip` 적용. 커밋·푸시는 보류했습니다.

## 동작

기존 판정·O/X·상황 변화·진동·시도 제한은 각 문제 화면이 계속 처리합니다. 기존 결과 연출 타이머가 끝나고 `settle()`을 실행한 직후에만 공통 팝업을 표시합니다. 별도 페이지로 이동하거나 정답 공개·재도전·보상을 실행하지 않습니다.

- 정답: 선택 파트너의 기쁜 모습, “정답입니다!”, “좋아요! 배려 있는 행동이었어요.”
- 오답: 선택 파트너의 아쉬운 모습, “오답입니다!”, “다시 생각해 볼까요?”
- 네 번째 실패: “정답을 함께 확인해 볼까요?”로 보조 문구만 변경합니다. 자동으로 정답을 공개하지 않습니다.
- 팝업 또는 바깥 영역을 탭하면 팝업만 닫습니다. 닫기 터치를 뒤의 재시도·해설·문제 조작으로 전달하지 않습니다.
- 자동 닫기 없음. 팝업이 열려 있는 동안 배경 조작을 차단하고 기존 상태를 보존합니다.
- 무효 드래그, 취소, 제출 전 선택·순서 변경, 06의 양해 터치는 팝업과 새 효과음을 발생시키지 않습니다.

## 시안과 에셋

팝업 너비는 `min(가용 너비 - 32, 344)`이고, 기본 높이는 최신 시안에 맞춰 **너비의 약 1.11배**입니다. 예를 들어 너비 344dp이면 높이는 약 382dp로, 344dp 고정 높이가 아닙니다. 큰 글자에서는 높이를 늘리고, 작은/가로 화면에서는 SafeArea 안에서 본문 스크롤을 허용합니다.

텍스트·O/X·카드·딤·꽃가루는 Flutter 위젯/그리기로 구현했습니다. ZIP의 캐릭터 투명 PNG 6개만 그림으로 사용합니다. 공통 원본 프레임 `(128,160,768,800)`은 모든 캐릭터의 가시 영역을 포함하며, 투명 여백만 줄여 크기와 발 기준선을 맞춥니다. 원본 PNG 자체는 변경하지 않았습니다.

정답 꽃가루는 950ms 동안 한 번만 재생하고 사라집니다. 오답에는 재생하지 않습니다. 시스템의 애니메이션 줄이기 설정도 따릅니다.

## 효과음

사용자 제공 `popup_correct.mp3`(약 2.769초), `popup_wrong.mp3`(약 0.627초)를 비트스트림 변환 없이 번들에 넣었습니다. 두 파일의 SHA256이 ZIP의 `audio_manifest.json`과 일치합니다. WAV와 참고 시안 PNG는 번들에 추가하지 않았습니다.

기존 효과음 콜백과 팝업 효과음은 같은 재생 큐를 사용합니다. 기존 소리가 끝난 뒤 새 소리를 판정당 한 번 재생합니다. 팝업을 닫아도 소리는 계속 재생하며, 빠르게 재시도할 때의 다음 소리도 큐에서 기다려 서로 겹치지 않습니다. 재생 함수의 Future는 **실제 소리가 끝날 때** 완료되는 계약입니다.

앱 진입점에서 실제 재생 함수를 주입하며 `audioplayers`의 완료 이벤트를 기다린 후 자원을 해제합니다. 오디오 실패는 학습 진행을 막지 않고, 음소거된 화면은 재생 요청을 보내지 않습니다. 오디오 플러그인을 사용하지 않는 독립 화면 테스트에는 가짜 재생 함수를 넣어 순서와 횟수를 확인합니다.

팀 검사 환경에 맞춰 `audioplayers 6.7.1`과 호환 플랫폼 패키지, `synchronized 3.4.0+1`을 lock에 기록했습니다. lock의 최소 요구 환경은 기존과 동일한 Dart 3.11 / Flutter 3.41입니다. `pub get --enforce-lockfile`로 해결 결과와 체크섬을 확인했습니다. 실제 CI 실행 자체를 완료했다고 표시하지는 않습니다.
