# 꾸미기 프로토타입

- 항목 순서: 모자, 의상, 액세서리, 가구, 소품, 배경.
- 구매/잔액/소유/장착 상태는 `fake/wardrobe_preview.dart`에서 관리한다. 상품 샘플은 `fake/wardrobe_samples.dart`에 있다.
- 화면은 주입된 WardrobeBinding에 구매·장착 의도를 전달한다. 실제 backend.dart 인터페이스, XP, 학습 기록, 영구 저장에는 변경이 없다.
- 착용 미리보기는 화면 내부 임시 선택이다. 적용하기로 소유한 항목을 반영하며 뒤로 가면 선택을 버린다. 구매 후에는 동일한 체험 세션의 꾸미기 목록에서 소유 상태로 표시된다.
- 기본 방은 기존 마이페이지 배경을 공유한다. 가구·소품·배경 변경은 마이페이지에도 반영한다.
- 상품 그림은 코드로 그린 일러스트이며 캐릭터 얼굴은 기존 디자인 원본을 재사용한다. 별도 대용량 이미지나 패키지는 추가하지 않았다.
- 사진풍 배경 요청은 이미지 생성 도구의 일일 한도로 미완료다. 현재 테마 배경은 임시 일러스트이며 WardrobeRoom의 배경 표시 부분을 교체할 수 있다.
- 체험 코인은 150으로 시작한다. 구매와 소유 상태는 앱 재실행 시 초기화된다. 실제 결제나 백업 기능이 아니다.

검증: 구매 취소/중복 구매/잔액 부족, 항목별 장착 및 잘못된 슬롯 거절, 적용 전 뒤로 가기, 여러 항목 동시 적용, 카테고리 필터, 모든 상품과 세 캐릭터 착용 렌더링, 마이페이지 상호작용.
