# 대중교통 01 백팩 드래그 문제

## 변경 파일

- `app/lib/screens/subway01_screen.dart`: 화면, 개별 PNG 합성, 마스크 판독, O/X·흔들림·진동, 힌트·재도전·해설.
- `app/lib/screens/action_drag_state.dart`: 좌표·포인터·판정·힌트·최종 실패 상태. XP 계산 및 저장 없음.
- `app/lib/screens/transport_lesson_screen.dart`: 대중교통 index 0에서 새 화면을 사용. 기존 문제 1의 저장 상태를 새 화면에 적용하지 않음.
- `app/lib/screens/transport_questions.dart`, `learning_catalog.dart`: 1번 제목·조작 유형·문구·검색어 변경. 5번을 비롯한 다른 문제는 유지.
- `app/pubspec.yaml`, `app/assets/subway01/`: 최신 패키지의 실제 PNG 및 JSON 등록. verification 합성 이미지나 ZIP 원본은 앱에 넣지 않음. 약 2.94MB, 새 패키지 없음.
- `app/test/subway01_test.dart`, `subway01_screen_test.dart`: 새 상태·위젯 회귀 테스트.
- `app/test/transport_lesson_test.dart`, `learning_screens_test.dart`: 1번 변경에 맞춘 기존 테스트 조정. 나머지 터치·드래그·선택·순서 문제 회귀 검사 유지.

## 에셋과 판정

입력: `manners_subway01_backpack_wearing_handoff.zip`, asset_rules schema 1.2. 모든 PNG는 제공된 원본 그대로 사용한다. 시작 마스크는 흰 픽셀의 red 채널 >127로 검사한다. 1536×1024 캔버스를 FittedBox로 비율 유지하여 표시하고, Listener의 변환된 로컬 좌표를 판정에 사용한다.

백팩은 초기 (821,610), 160×174. 포인터 최초 위치부터의 이동량만 더하므로 잡는 즉시 이동하지 않는다. 누르면 어깨끈을 숨기고 이동 거리 20px를 넘으면 가방을 캐릭터 앞으로 올린다. 판정은 손가락 위치가 아닌 백팩 중심으로 JSON의 correct/wrong/drag_bounds 다각형을 검사한다. 다른 포인터는 무시한다. 무효 위치, 화면 밖, 취소는 무료 복귀한다.

## 상태와 학습 흐름

힌트는 별도 0~2단계이며 판정 횟수에 포함하지 않는다. 유효한 오답만 최대 4번 집계한다. 정답·오답 직후 1초 동안 입력을 잠그고 O/X를 표시한다. 오답 시 상황 그림만 처음 0.2초 흔들고 지원 모바일 플랫폼에서 약한 진동을 한 번 요청한다. 움직임 감소 설정에서는 확대·흔들림을 생략한다.

정답은 완료 장면과 문구를 유지하고 해설로 이동한다. 재시도는 백팩·어깨끈·표정·효과를 복원한다. 최종 실패는 재시도를 차단하고 사용자가 정답 확인을 눌렀을 때만 정답 장면을 보여준다. 화면 재진입 시 시도와 힌트는 초기화한다. 성공이나 정답 확인으로 가짜 XP·저장 기록을 만들지 않는다. 실학습 기록 연결은 기존 합의대로 backend API 확정 후 수행한다.

## 요청서와 자료의 차이

- ZIP 매핑 일부는 정답 후 힌트를 표시하거나 최종 실패 즉시 정답 장면을 지정한다. 요청서를 우선해 정답 후 힌트를 숨기고, 최종 실패 시 정답 확인 버튼을 거친다.
- 초기 UI 시안의 상황 영역은 세로에 가깝다. 요청서의 원본 비율 보존을 우선해 실제 1536×1024 장면은 가로 3:2로 표시한다. 캐릭터와 가방을 늘이거나 시안에 합쳐진 그림을 재사용하지 않는다.
- 로고는 기존 화면처럼 Flutter 텍스트로 표시한다. 제공 시안의 로고 전용 원본 글꼴과 완전히 동일한 형태는 아니다.
- 진행도는 요청한 01/20 표기를 사용한다. 다른 문제 추가나 전체 문제 목록의 20개 확장은 이번 범위에 포함하지 않는다.

`subway01_screen_test.dart`: 320px·430px에서 실제 마스크가 있는 백팩 드래그, 배경 터치 무시, 오답·재시도·정답·해설 이동 및 초기/오답/정답 이미지 캡처. 테스트 사이 AssetBundle 캐시를 비워 독립 실행을 보장한다.

실행 로그와 화면은 저장소 밖 `Documents/Codex/subway01-review/`에 보관한다. Android 실기기 진동·손가락 조작감, iOS 및 브라우저 수동 조작은 별도 확인이 필요하다. 전체 앱 테스트 재실행 결과와 관련 테스트 결과를 구분해서 보고한다.

## 재사용과 다음 단계

ActionDragState의 포인터 추적·상대 이동·다각형 판정·힌트·재시도 관리를 다른 행동형 문제에 재사용할 수 있다. 원래 요청서에 고정된 최대 4회와 캔버스 크기는 이 문제 기준이다. 다른 행동형 문제 도입 때 그 문제의 JSON 규칙에 맞춰 확장한다.

다음 단계는 Android에서 조작과 진동을 확인하고, backend의 행동 입력·정답 판정 인터페이스 확정 후 성공/실패 및 학습 완료를 연결하는 것이다. 응용 문제는 구현하지 않았다.
