로고·헤더·진행도·Pretendard·힌트·O/X·공통 결과 팝업·효과음 대기열·기존 해설을 재사용한다. 힌트와 해설 프로필도 02번 기본 화면의 확정 에셋을 사용한다. 다른 문제의 판정·아트·보상 구현은 수정하지 않았다.

## 에셋과 좌표

- 원본 ZIP의 Manifest **51개 파일**에 대해 크기와 SHA-256 일치를 확인했다.
- 런타임 PNG **22개**, 명세 JSON **4개**를 원본 그대로 사용했다. `preview/`, `approved/`, `qa/`는 앱에 포함하지 않는다.
- 등록한 파일의 크기·해시는 `app/assets/application02/source_sha256.json`에 별도 기록했다. 원본 전체 Manifest는 저장소 밖 검수 폴더의 ZIP 추출본에 보존한다.
- 실제 장면은 1536×1024 좌표계다. PNG의 불투명 경계를 구해 시각적 발 아래 중심을 기준으로 배치한다. 투명 여백이 다른 대기·보행 에셋도 같은 발 위치를 유지한다.
- 배경 → 고정 잔류 승객 → 발 위치로 깊이를 정렬한 하차 승객 → 선택 캐릭터 → 공통 피드백 순서다. 초기 객실의 가림·혼잡 표현은 유지한다.

## 드래그와 안전 판정

화면 전체가 아닌 실제 장면 사각형으로 손가락 좌표를 환산한다. 잡은 위치와 발 사이의 오프셋을 유지하며, 드래그 종료 시 발 기준점으로 판정한다. 이동 중에는 채점하지 않는다. 작은 승강장 캐릭터의 잡기 영역은 최소 48dp로 보완하며 **정답 폴리곤 자체는 확대하지 않는다**.

판정 우선순위는 다음과 같다.

1. 2단계 안전 플래그 미충족: 조작 차단, 횟수 무차감.
2. 장면 밖·구조물: 무효, 원위치 복귀, 횟수 무차감.
3. 안전선·하차 통로·문 앞 등 지정 위험 영역: 유효 오답.
4. 안전한 발 기준점 의도 폴리곤: 지정 좌표로 스냅.
5. 나머지 배경: 무효.

`drag_zones.json`의 v7 폴리곤을 그대로 사용하고 몸 전체 사각형 포함 조건을 적용하지 않는다. 오른쪽 기둥·배경 보행자·안전선을 정답으로 허용하지 않는다. 작은 화면에서 첫 드래그가 스크롤로 넘어가는 문제는 장면 내부 제스처를 분리해 해결했다. 드래그 중 장면 사각형이 변하지 않는 것도 포인터 테스트에서 검사한다.

## 승객 이동과 상태 관리

다섯 명은 각자 출발 전까지 대기 PNG를 사용한다. `exit_tote → exit_backpack → exit_office → exit_woman → exit_man` 순서로 270ms 간격 출발하고 각 670ms간 이동한다. 발 키프레임·배율을 구간 보간하고, 출발 후 로컬 시간 130ms마다 보행 A/B를 바꾼다. 투명도를 줄여 숨기지 않고 화면 아래로 완전히 이동한 후 제거한다. 잔류 승객과 승강장 캐릭터는 고정한다.

실제 하차 시간 완료 및 다섯 경로 완료를 확인한 뒤 `exiting_complete`를 설정한다. `train_stopped`, `doors_fully_open`, `reboarding_safe`도 모두 참일 때만 재승차를 허용한다. 플래그 갱신 함수는 재승차 드래그·스냅·판정 도중 안전 조건이 해제되면 무차감으로 중단한다. 현재 정적 교육 장면의 기본값은 정차·문 개방·안전 경로 확보 상태이며, 실제 열차 센서에 연결하는 기능은 아니다.

앱이 비활성화되면 진행 중인 연출을 멈추고 복귀 시 이어간다. 손가락 드래그는 취소한다. 두 번째 포인터는 무시한다. 다시 풀기는 현재 문제의 캐릭터 위치·단계·힌트·오답 횟수·안전 상태를 초기화한다.

## 시도·해설·보상

1단계 성공은 최종 O·팝업·XP를 발생시키지 않는다. 오답 횟수는 두 단계 전체에서 합산하여 최대 4회다. 네 번째 유효 오답 뒤에는 공통 실패 팝업을 보여 주고, 사용자가 **정답 확인**을 눌러야 최종 위치를 공개한다. 공개 상태는 직접 성공이 아니며 정답 O·정답 팝업·XP를 발생시키지 않는다. 힌트는 기존 1→2 순서다.

ZIP에는 별도의 응용 교육 원문이나 02번 주제 완료·리워드 설계가 없다. 기존 02번 교육 원문과 공통 해설 화면을 재사용했다. v7의 `grants_xp_directly: false`에 따라 이 문제 화면에는 XP 지급·저장을 추가하지 않았다. 기존 기본 문제 완료 기록과 보상 규칙은 유지한다. 01번의 정답 공개 +10 XP 설정을 이 문제에 복사하지 않았다. 주제별 최종 보상은 후속 완료 연결에서 별도 확정해야 한다.

## 남은 검수와 아트 제한
