## 합성과 말풍선

1620×938 전체 캔버스를 원점 (0,0)에서 한 번만 `BoxFit.contain`으로 변환한다. 인물 PNG를 별도로 자르거나 캐릭터별로 배율을 바꾸지 않는다.

그리기 순서는 배경 → 앉은 승객 → 옆 승객 → 선택 캐릭터 1명 → 옆 승객 감정선 → 주인공 감정선 → Flutter 말풍선이다. 캐릭터 3종의 공통 발 좌표 (335,901)를 유지한다. `runtime_reuse_all_visual_states`에 따라 선택·힌트·정답·오답 상태에서도 승인된 동일 장면 에셋을 재사용하고, 판정 표현은 공통 위젯으로 표시한다.

말풍선은 기존 말풍선 파일의 기본 힌트 모양을 유지하면서 장면용 타원형 변형을 추가했다. 배경이나 승객 PNG에 글자를 합성하지 않는다. 본체·꼬리·줄바꿈·테두리는 명세에서 읽는다.

- 본체: (938,105)~(1361,348).
- 꼬리 끝: (1186,385). 본체 중심보다 오른쪽·아래에 있으며 옆 승객을 향한다.
- 테두리: 씬 기준 5px.
- 문구: `저 자리,` / `괜찮은 걸까?` 2줄, 기존 Pretendard 사용.
- 힌트·해설 프로필은 기존 공통 선택 캐릭터 에셋을 재사용한다.

## 선택·판정·기록

정답은 원본 JSON의 **B**다. 선택 시에는 선택 표시만 바뀌고, 제출해야 횟수 증가와 판정을 실행한다. 제출 중 중복 제출을 막고, 최초 1회+재도전 최대 3회의 총 4회 유효 제출을 적용한다. 힌트는 1→2 순서이며 횟수를 차감하지 않는다.

네 번 실패하면 정답 확인을 제공하고 B를 학습용으로 공개한다. 공개 상태는 성공이 아니며 정답 팝업이나 XP 지급을 발생시키지 않는다. 다시 풀기는 선택·풀이 횟수·힌트를 초기화한다. 기존에 저장된 다른 문제의 완료 기록·XP는 변경하지 않는다.

현재 03번용 세트 완료·보상 정책과 지급 API는 연결되어 있지 않다. 명세의 `next_screen_on_explanation`은 향후 공통 주제 완료 연결 지점을 가리킨다. 이번에는 기존 후속 문제 콜백을 보존하고 새 XP 계산·지급·저장을 추가하지 않았다. 01번의 보상 설정을 복사하지 않았다. 실제 03번 완료·리워드 연동은 후속 작업이다.

## 교육 콘텐츠 승인 상태

**교육 문구는 미승인 초안이며 최종 확정하지 않았다.** `content_is_draft: true`를 확인했고 제공된 `education_content_transit03.md`를 원본 그대로 보관한다.

핵심 매너·학습 핵심·캐릭터 한마디, 이유 3개, Q&A 3개, 권장 예절/법적 의무 구분, 제시된 출처 3개를 기존 해설 UI에 연결했다. 문서 승인 메타데이터는 이 보고서에서 구분하며, 장면 속 승객의 실제 임신 여부는 공개하지 않는다.

출처 URL은 원문대로 표시하고 기존 링크 열기 동작을 재사용한다. 이번 작업에서 외부 사이트 접속이나 의료·법률 내용의 사실 검토를 수행한 것은 아니다. 제공된 설명의 교육 편집적 타당성과 최종 표현은 콘텐츠 승인 단계에서 확정해야 한다.

## 시안 비교와 아트 확인 사항

실제 Flutter 합성 화면과 승인 장면을 같은 1620×938 기준으로 비교했다. 원본의 복원 배경·캐릭터 PNG를 그대로 사용했으며 그림을 다시 그려 차이를 숨기지 않았다.

- 오른쪽 창틀·벽면과 세 번째 손잡이는 자료에 기록된 국소 추정 복원 영역이다. 실행 화면에서도 원래 승인 래스터와 형상·선 연결이 완전히 같지는 않다.
- 좌석 프레임·복원 배경의 윤곽도 원래 평면 시안과 차이가 있다. Flutter에서 독립 레이어를 옮기거나 자른 결과라고 주장하지 않으며, 제공 v8 PNG에 포함된 형상이다.
- 댕댕이는 제공된 생각하는 자세, 냥냥이·몽몽이는 제공된 승인 서 있는 자세다. 후자의 별도 생각하는 자세는 ZIP에 없으므로 만들어 교체하지 않았다.
- 댕댕이 오른쪽 귀·볼과 손의 추출 윤곽, 창틀·손잡이 접합부는 확대 비교 자료로 확인할 수 있다. 픽셀 단위 원본 일치나 새 아트 승인을 주장하지 않는다.
- 말풍선은 실제 Flutter 타원·꼬리·텍스트다. 승인 래스터와 좌표·비율은 맞추지만 글자와 곡선의 픽셀까지 같은 이미지인 것은 아니다.

추가 필수 런타임 PNG 누락은 발견하지 않았다. 생각하는 자세를 세 캐릭터 모두 같은 형태로 맞추고 싶다면 별도의 승인 포즈가 필요하다.
