# 프론트엔드 그림 원본 안내

원본 PNG는 저장소에 포함하지 않습니다. 앱은 `app/assets/`의 WebP만 사용합니다.

원본 공유 위치: [팀 Notion 디자인 자료](https://app.notion.com/p/40400ce1e43d81519998dd27d0619fa0?source=copy_link)
원본 파일은 위 공유 위치에서 관리합니다. 공유 페이지의 원본 업로드 상태와 팀원 접근 권한은 별도로 확인해야 합니다. 원본 파일을 이 폴더에 다시 커밋하지 않습니다.

## 원본에서 WebP를 추출한 좌표

좌표는 원본 PNG의 왼쪽 위를 `(0, 0)`으로 하는 픽셀 단위 `(x, y, 너비, 높이)`입니다.
출력 파일은 자른 크기를 유지하며, 아래 좌표는 현재 앱 그림을 만들 때 사용한 값입니다.

| 문제 원본 폴더 | question_1~10.png 자르기 좌표 |
| --- | --- |
| transport | `(510, 301, 298, 247)` |
| public | `(491, 275, 360, 380)` |
| school-work | `(510, 303, 345, 300)` |
| digital | `(495, 278, 370, 345)` |
| conversation | `(50, y, 760, 300)`: 1번 y=880, 4번 y=914, 8번 y=900, 나머지 y=874 |

`action_scenes.png`, 성공 장면, `characters.png`, `design_reference.png`, `growth_stages.png`는 전체 크기와 투명도를 유지해 WebP로 변환합니다.
성장 스프라이트는 1536×2048 기준으로, 캐릭터 열과 성장 단계 행마다 512×512 영역을 표시합니다.
이미지 품질은 기본 88(카테고리 썸네일 85)이며, 100,000바이트를 초과하면 품질을 5씩 낮춰 최소 45까지 조정했습니다.

## 캡처 테스트 글꼴

개인 PC 경로는 저장하지 않습니다. 캡처가 필요하면 다음 값을 직접 전달합니다.

- `--dart-define=PREVIEW_FONT=<한글 글꼴 경로>`
- `--dart-define=PREVIEW_ICONS_FONT=<MaterialIcons 글꼴 경로>`
- 시작 화면은 기존 `WELCOME_PREVIEW_FONT`, 파트너 화면은 기존 `PREVIEW_FONT` 설정을 사용합니다.

일반 테스트는 글꼴 경로 없이 실행할 수 있습니다.
