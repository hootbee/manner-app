# 프론트엔드 그림 원본

이 폴더는 디자인 참고용 PNG 원본입니다. 앱의 assets 번들에 포함하지 않습니다.
앱은 app/assets/ 아래의 WebP를 사용합니다. 문제·카테고리 썸네일은 기존 화면의 자르기 좌표로 추출했습니다.
여러 장면을 묶은 스프라이트는 좌표와 투명도를 유지했습니다.

## 캡처 테스트 글꼴

개인 PC 경로는 저장하지 않습니다. 캡처가 필요하면 다음 값을 직접 전달합니다.

- `--dart-define=PREVIEW_FONT=<한글 글꼴 경로>`
- `--dart-define=PREVIEW_ICONS_FONT=<MaterialIcons 글꼴 경로>`
- 시작 화면은 기존 `WELCOME_PREVIEW_FONT`, 파트너 화면은 기존 `PREVIEW_FONT` 설정을 사용합니다.

일반 테스트는 글꼴 경로 없이 실행할 수 있습니다.
